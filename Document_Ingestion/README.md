# Preserved Original Scripts

The Python scripts in this directory are the original development files. They
are retained for reference and have not been removed.

The production CLI and maintained implementation live in
[`src/rag_practice`](../src/rag_practice/). Use that package for normal
development and execution:

```powershell
rag-practice ingest
rag-practice ask "Your question here"
```

The original scripts may rely on the old working-directory layout and are not
the supported CLI entry point.
